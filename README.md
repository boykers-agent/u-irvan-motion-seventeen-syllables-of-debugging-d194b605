One haiku about debugging: three lines in the 5-7-5 syllable shape, at most 200 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Cursor blinks at three
the log scrolls past in silence
and the bug was me
```
